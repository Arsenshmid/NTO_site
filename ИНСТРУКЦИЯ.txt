  эту ошибку — ничего чистить не нужно (миграция откатилась целиком):
  просто замените файлы sql\10_mkd_map_points.sql и app.py и выполните

- На карте теперь показываются ВСЕ НТО из базы (84 из 92 имеют координаты;

     - 463 дома (с координатами — 406, без координат — 57, см. PRINT в SSMS);

       16 неопределённых, 14 запросов ЕГРН, 1 снесённый;
     - 32 УК из справочника;
     - привязка домов к УК по названию.

   Повторный запуск безопасен: MERGE обновляет существующие записи, дубликаты
   не создаёт. Снесённые дома помечаются IsDemolished=1 (остаются в базе,
   но на карте не показываются).

- С waitress зависания должны исчезнуть полностью.

ШАГ 7а. ПУБЛИКАЦИЯ В ИНТЕРНЕТЕ (доступ из любой точки мира)
====================================================================
Сайт можно открыть для обычных людей по ссылке из интернета,
при этом сервер остаётся на вашем рабочем ПК. Используется
Cloudflare Tunnel — бесплатно, шифрование https, НЕ требует
публичного IP и НЕ открывает порты наружу (безопасно).

Как опубликовать:
1. Запустите сайт как обычно: python app.py (порт 8080).
2. Запустите файл C:\NTO\start_internet.bat (двойной клик).
   - При первом запуске он скачает cloudflared.exe (~50 МБ, один раз).
   - Антивирус/SmartScreen может спросить — разрешите.
3. Подождите 10–20 секунд. В окне появится строка вида:
   https://xxxx-yyyy-zzzz.trycloudflare.com
   Это и есть публичная ссылка — скопируйте её.
4. Отправьте ссылку сотрудникам (вход по паролю) и гражданам
   (просмотр без входа: реестры, карта, статистика).

ВАЖНО:
- Пока окно туннеля открыто — ссылка работает. Закрыли — ссылка
  «умерла». При новом запуске туннеля ссылка будет НОВАЯ
  (это ограничение бесплатного quick-режима).
- Для ПОСТОЯННОЙ ссылки (не меняется при перезапуске):
  зарегистрируйте бесплатный домен на Cloudflare и выполните
  «cloudflared tunnel login» — см. инструкцию Cloudflare
  «Named Tunnels». Мы поможем при необходимости.
- Пароли в config.json — не показывайте публичную ссылку без
  необходимости; вход только для сотрудников.
- Граждане видят только просмотр: реестр НТО/МКД, карту, файлы-
  фото. Документы (не фото) и вся правка — только после входа.

ЧТО ДЕЛАТЬ, ЕСЛИ...
====================================================================
1) «Сообщение 4902: Не удалось найти объект dbo.nto_object»
   Причина: вы запустили SQL-запрос в базе master, а таблица в NtoDB.
   Решение: в SSMS вверху редактора выберите NtoDB (не master),
            или добавьте в начало запроса: USE NtoDB; GO

2) «Произойдет усечение строковых или двоичных данных в столбце authority»
   Причина: столбец authority был NVARCHAR(300), а значение длиннее.
   Решение: выполните миграцию 05_widen_text_columns.sql.
            После этого столбец будет NVARCHAR(1000) — хватит для длинных выписок ЕГРН.
            В новой версии app.py тоже есть защита от усечения — автоматически обрезает.

3) «'ер' is not recognized» в командной строке при запуске run_site.bat
   Причина: в предыдущей версии bat-файл содержал русские буквы в команде echo,
            которые cmd не мог разобрать из-за кодировки.
   Решение: в версии 4 bat-файл переписан, этой ошибки больше нет.

4) Не работает авторизация (ввожу admin/пароль — не пускает)
   Причина: в версии 4 изменилась система авторизации.
            Теперь нужно вводить ЛЮБОЕ имя (например, Арсен) и пароль из config.json
            (admin_password или editor_password), а не "admin"/"editor" как раньше.
   Решение: откройте C:\NTO\config.json, посмотрите admin_password.
            Войдите: имя = ваше имя, пароль = admin_password.
            Старые пароли из "users" тоже работают (для совместимости).

5) «База МКД не подключена»
   Решение: в config.json добавьте/исправьте "database_mkd": "AvtodorDB".
            Перезапустите сайт.

6) Вкладка МКД показывает «Загрузка...» и не работает
   Причина: либо не настроена database_mkd, либо в AvtodorDB нет таблицы House.
   Решение: проверьте config.json; если МКД раньше работала в avto_web1 —
            значит база AvtodorDB существует и таблицы в ней есть.
            Просто убедитесь, что database_mkd указывает на неё.

7) «Сообщение 547: Конфликт инструкции INSERT с ограничением FOREIGN KEY
   FK__nto_map_p__...» при выполнении миграции 10
   Причина: старая версия скрипта 10 (до 20.11) не снимала ограничение
            внешнего ключа object_id → nto_object, а точкам МКД нужно
            записывать туда номера домов из базы AvtodorDB.
   Решение: возьмите обновлённый файл sql\10_mkd_map_points.sql (из архива
            от 20.11 или скачанный отдельно) и выполните его ПОВТОРНО —
            теперь он сам снимает ограничение и печатает:
            «Снято ограничение внешнего ключа (мешал точкам МКД): ...».
            Повторный запуск безопасен: дубликаты не создаются.
            Заодно замените app.py (новая проверка ссылок на НТО).

НОВОЕ В ВЕРСИИ 6.4 (карта НТО)
====================================================================
- Фильтр карты «В схеме / Все НТО / Вне схемы» (в тулбаре карты).
  По умолчанию — ТОЛЬКО НТО В СХЕМЕ (вне схемы скрыты).
- Светофор договоров: зелёный — свежий, жёлтый — истекает (<90 дней),
  красный — истёк или на грани (<30 дней), синий — в схеме без срока.
- «❗ требует внимания»: пульсирующий значок над маркером, плашка
  в карточке, ❗ в списке. Кнопки в попапе точки и в карточке НТО
  (войдя как editor/admin). Заметка пишется в журнал изменений.
- Колонки IsAttention/AttentionNote сайт добавит в NtoDB сам при
  первом запуске (миграция руками НЕ нужна; sql/12 — для порядка).
- Список НТО: фильтр «В схеме» теперь выбран по умолчанию.

====================================================================
КАК ПОЛЬЗОВАТЬСЯ
====================================================================
- Просмотр и поиск — без входа.
- Вход (имя + пароль) → admin: всё; editor: добавление/правка, без удаления и журналов.
- Вкладка «НТО»: 92 объекта, поиск, фильтры, карточка, файлы, журнал.
- Вкладка «МКД»: 448 домов (в вашей базе), поиск по адресу/УК, фильтры
  (аварийные/без УК/аукцион), карточка дома со всеми блоками
  (реестр/аварийность/без УК/контакты).
- Кнопка «Карта» — интерактивная карта округа: подложка с автопереключением,
  граница округа, переключатель «НТО / МКД»; клик по точке — информация,
  клик по дому — карточка МКД; admin/editor может добавлять и двигать точки.
- Кнопка «Онлайн» (admin) — список активных пользователей с IP и компьютером.
- Журнал НТО (admin) — кто, когда, с какого компьютера, что изменил.
- Журнал МКД (admin) — то же для базы МКД.
